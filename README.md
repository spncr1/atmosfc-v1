# Atmos FC

AtmosFC.io analyses fan sentiment and reactions from Reddit post-match threads and visualises how crowd mood shifts across 90 minutes of a football match, to solve (x) problem...

## Stack

- Backend: Python, FastAPI, Football-Data.org, PRAW, VADER
- Frontend: vanilla HTML, CSS, JavaScript, Chart.js
- Backend deploy target: Railway
- Frontend deploy target: Vercel
